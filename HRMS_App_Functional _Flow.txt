📱 HRMS Mobile Application – User Flow & Functional Steps
Step 1: Sign Up (New User Registration)

The user must complete the following mandatory fields:

A. Username
B. Email ID (Must be a valid email address)
C. Phone Number (Must be a valid mobile number)
D. State
E. District (Field District)
F. Taluka (Field Taluka)
G. Password (Minimum 6 characters)

After filling in all required details, the user can complete the Sign Up process.

Step 2: Sign In

The user can log in using:

A. Email ID or Mobile Number
B. Password

Step 3: Successful Login

Once the user logs in successfully, the application navigates to the Dashboard screen.

Step 4: Office Login Form (Dashboard → Office Login)

The user opens the Office Login Form from the Dashboard.

Form Fields:

A. Username – Auto-filled
B. Field Location (Taluka) – Auto-filled (Only Taluka is displayed)
C. Time – Automatically filled with the current time
D. Date – Automatically filled with the current date
E. Get Location

On clicking Get Location, the app requests location permission

Captures the current latitude & longitude

Displays the captured location in a popup

After clicking OK, the latitude and longitude are shown in the input fields
F. Capture Selfie

On clicking Capture Image, the app requests camera permission

Captures the user’s selfie

Displays latitude & longitude in a popup

After clicking OK, the captured selfie is shown in the image preview
G. Submit

Important Logic:

If the user mistakenly submits the Logout form first, the system considers it as Leave.

Once the Office Login form is submitted successfully, the Login Time and Date are displayed in the Time History section.

Step 5: Office Logout Form (Dashboard → Office Logout)

After office login, the user can submit the Office Logout Form.

Form Fields:

A. Username – Auto-filled
B. Field Location (Taluka) – Auto-filled
C. Time – Automatically filled with the current time
D. Date – Automatically filled with the current date
E. Get Location

Requests location permission

Captures current latitude & longitude

Displays location in a popup

On clicking OK, the values are filled in the input fields
F. Capture Selfie

Requests camera permission

Captures selfie image

Shows latitude & longitude in a popup

On clicking OK, the selfie image is shown in preview
G. Submit

Result:

After successful logout submission, the following details are shown in Time History:

Login Time

Logout Time

Total Working Hours

Date

Step 6: Profile Section

The user can open the Profile screen from the Dashboard.

Profile Fields:

A. Username – Auto-filled
B. Email ID – Auto-filled
C. Phone Number – Auto-filled
D. State – Auto-filled
E. District – Auto-filled
F. Taluka – Auto-filled

Profile Update Process (One-Time Only):

G. Upload Profile Image (Mandatory – One-time update)
H. Bank Details Entry

Account Holder Name

Bank Account Number

IFSC Code
On entering a valid IFSC code, the following fields are auto-filled:

Bank Name

Bank Branch Name

MICR Number

Select Account Type
I. Click Submit

A success popup is displayed

On clicking OK, the user is redirected to the Dashboard

Important Note:

Profile Image and Bank Details can be updated only once

On subsequent visits to the Profile page:

Submit and Cancel buttons will not be visible
